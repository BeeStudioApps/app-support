# BeeStudioApps Support

This repository is the public GitHub Pages source for Numplo and Beat4 support.

## Pages

- `/numplo/privacy/` — Numplo Privacy Policy
- `/numplo/support/` — Numplo Support
- `/beat4/privacy/` — Beat4 Privacy Policy
- `/beat4/support/` — Beat4 Support

The production base URL is `https://beestudioapps.github.io/app-support/`.

## Publish with GitHub Pages

In the repository’s **Settings → Pages**, select **Deploy from a branch**, then select the `main` branch and the `/ (root)` folder. GitHub Pages is available on GitHub Free for public repositories.

Before publishing a material policy change, check the app’s active release configuration, the store privacy/data disclosures, provider documentation, and the support contact. The in-app links use the four URLs above, so keep those paths stable.

## Local checks

Run `./script/check-html.sh` from the repository root. It checks the required Pages files and links used by the app.
